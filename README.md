# Hero Vired — Multi-Cloud Architecture & DevOps

My notes, hands-on labs and assignments from the **Hero Vired PG Programme in Multi-Cloud Architecture & DevOps**
(started July 2026), taken alongside my MCA at CMR University, Bengaluru.

I already run a production platform on Kubernetes ([Sougba](https://samibrahima.tech/sougba.html)); this programme is
where I go deeper on cloud providers (AWS first), infrastructure as code and automation.
